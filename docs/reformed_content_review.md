# Reformed Content Review

Checklist para revisar conteudo doutrinario da base.

## Checklist

- [ ] A pergunta e fiel ao texto biblico?
- [ ] A explicacao e biblica?
- [ ] A doutrina esta alinhada a Biblia e a tradicao cristã historica?
- [ ] Esta compreensivel para leigos?
- [ ] Evita polemica desnecessaria?
- [ ] Ajuda a pessoa a amar mais a Biblia?
- [ ] A difficulty esta adequada?
- [ ] O level esta coerente?
- [ ] A referencia sustenta a resposta?
- [ ] A pergunta poderia ser mal interpretada?
- [ ] Precisa revisao pastoral humana?

## Observacao

Mesmo com revisao automatizada, perguntas doutrinarias sensiveis devem passar por revisao humana antes de publicacao ampla.
